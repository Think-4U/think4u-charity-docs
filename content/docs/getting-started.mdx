## Browse by topic

Start with the sidebar to explore the available guides. On a smaller screen, open the navigation menu to see the same pages.

## Find a specific answer

Open search and enter a few words about your topic. Select a result to jump to the matching page.

## Choose your reading experience

Use the theme control to switch between light and dark mode. Longer pages include a table of contents so you can jump directly to a section.

## Read with an AI assistant

Use **Copy Markdown** on a documentation page to copy its content. The [documentation index](/llms.txt) and [complete documentation](/llms-full.txt) are also available as plain text.

## Contribute a guide

See [Writing documentation](/docs/writing) for the page format and navigation conventions.
