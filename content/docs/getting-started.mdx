## When the website asks you to sign in

Follow the sign-in or sign-up option shown on the official website. Use only the login methods offered there, and enter a verification code only in the verification flow you started. Do not send passwords or OTPs to a coordinator or include them in a support message.

If you cannot access your account, use the [public contact form](https://think4u.org/contact). This documentation cannot view accounts, check private donation records, or issue receipts.

## Find an answer quickly

Use search or browse the sidebar. The [frequently asked questions](/docs/faq) cover common donation and participation questions; the [quick links](/docs/quick-links) lead directly to public website pages.

## If you are outside India

The main website currently restricts access and donation services to India. Foreign contributions are not accepted while FCRA authorization is pending. If access is restricted or your location is detected incorrectly, [contact the team](/docs/about/contact); do not bypass the restrictions.
