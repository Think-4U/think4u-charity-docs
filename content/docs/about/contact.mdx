## Choose the right support route

| What you need | Guidance |
| --- | --- |
| Donation status, receipt, duplicate payment | [Payment and receipt support](/docs/donations/receipts-and-refunds) |
| Volunteer or student application | [Volunteer guide](/docs/participate/volunteer) or [Campus Ambassadors](/docs/participate/campus-ambassadors) |
| Institutional collaboration | [Partner guide](/docs/participate/partners) |
| Formal complaint, safeguarding, or privacy issue | [Grievances](/docs/policies/grievances) |
| Suspected website vulnerability | [Responsible security reporting](/docs/policies/security-and-reporting) |

Include a short description and the relevant page or program name. Send personal transaction details only through the official support route when needed. Never send a password, OTP, UPI PIN, CVV, or complete card number.
